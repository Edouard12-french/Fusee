# Gagner de l'argent avec des jeux web

## itch.io (le plus simple pour démarrer)
- Jeu HTML5 : zip du dossier avec index.html, type « HTML », taille d'écran fixée, bouton plein écran.
- Prix : gratuit avec dons (« pay what you want ») pour démarrer et se faire connaître ; payant (2-10 €) quand le jeu
  est riche ou vise une niche. itch.io prend une part réglable (10 % par défaut).
- Page : capture animée (GIF) en premier, 3-5 captures, description courte avec ce qui rend le jeu unique, tags précis.
- Visibilité : participer aux **game jams** (énorme source de joueurs), publier des devlogs, vidéos courtes du
  gameplay, mises à jour régulières.
- Paiements reçus sur un compte PayPal/Stripe **au nom d'un parent** si on est mineur.

## Portails de jeux web
Des portails (CrazyGames, Poki…) partagent des revenus publicitaires avec les développeurs ; ils sélectionnent les
jeux (qualité, mobile, chargement rapide, intégration de leur SDK). Lire leurs conditions avant d'envoyer.

## Ce qui fait un bon jeu web
Compréhensible en 5 s sans tutoriel · une boucle de jeu courte et addictive · progression (scores, niveaux,
déblocages) · « encore une partie » · marche au toucher sur mobile · chargement < 3 s · sons simples.
Toujours original : pas de copie de jeux, personnages ou marques existants.
Vérifier avec browser_test (démarre, réagit, aucune erreur) avant de montrer.
