# Fusee

## Jeu : Fusée Kármán

Jeu d'arcade dans le navigateur : la fusée monte à travers l'atmosphère jusqu'à la ligne de Kármán (100 km) et au-delà. Il faut esquiver les obstacles et ramasser les bidons de carburant.

Pour y jouer en local, ouvre `jeu/index.html` dans un navigateur.

### Publier sur itch.io

1. Compresse le dossier `jeu` en `.zip` (le fichier `index.html` doit être à la racine du zip).
2. Sur itch.io : « Upload new project », « Kind of project » = **HTML**.
3. Envoie le zip et coche « This file will be played in the browser ».
4. Taille conseillée : 960 × 640, avec le bouton plein écran activé.
5. Prix : « No payment required » avec dons, ou « Pay what you want ».
